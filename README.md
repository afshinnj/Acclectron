# Acclectron

نرم‌افزار حسابداری دسکتاپ فارسی برای فروشگاه‌ها و کسب‌وکارهای کوچک؛ ساخته‌شده با Electron و JavaScript، با ذخیره‌سازی محلی و آفلاین در SQLite.

Acclectron چرخهٔ روزانهٔ فروشگاه را در یک برنامهٔ سبک پوشش می‌دهد: تعریف کالا و طرف‌حساب، خرید و فروش، کنترل موجودی، صندوق و هزینه‌ها، دریافت/پرداخت، گزارش‌های مالی و پشتیبان‌گیری.

## امکانات

- داشبورد مدیریتی با خلاصهٔ فروش، موجودی، بدهکار/بستانکار و اعلان‌ها
- فروش روزانه و صدور فاکتور فروش و خرید با محاسبهٔ تخفیف، مالیات و تسویه
- مرجوعی جزئی یا کامل فروش و خرید، همراه با برگشت موجودی و ثبت مالی
- مدیریت کالا، دسته‌بندی، واحد اندازه‌گیری، قیمت خرید/فروش و حداقل موجودی
- طرف‌حساب‌ها و صورت‌حساب گردش حساب بر اساس فاکتور، دریافت، پرداخت و مرجوعی
- صندوق، هزینه‌ها، چک‌ها، اقساط و دریافت‌های دوره‌ای
- انبارگردانی و اصلاح موجودی با ثبت دلیل و لاگ حسابرسی
- گزارش فروش، سود و زیان، موجودی و بستن حساب روزانه
- کاربران، نقش‌ها، تغییر رمز عبور و لاگ عملیات
- پشتیبان‌گیری خودکار/دستی و بازیابی پایگاه‌دادهٔ SQLite
- خروجی CSV سازگار با Excel و چاپ/خروجی PDF
- رابط راست‌به‌چپ و فارسی، مناسب استفادهٔ آفلاین در ویندوز

## شروع سریع برای توسعه

پیش‌نیاز: Node.js نسخهٔ LTS و npm.

```bash
npm install
npm start
```

برای اجرای بررسی‌های کیفیت:

```bash
npm run check
npm test
```

برای ساخت نسخهٔ قابل‌حمل ویندوز (بدون نیاز به نصب):

```bash
npm run release
```

خروجی ZIP، فایل SHA-256 و مانیفست انتشار در پوشهٔ `dist` ساخته می‌شوند.

## ورود نخستین

در اولین اجرا:

- نام کاربری: `admin`
- رمز عبور: `admin123`

پس از ورود، رمز پیش‌فرض را از بخش «کاربران و لاگ» تغییر دهید و کاربران موردنیاز را بسازید.

## داده‌ها و پشتیبان‌گیری

اطلاعات در پایگاه‌دادهٔ محلی SQLite ذخیره می‌شود و برای کار عادی به اینترنت نیاز نیست. مسیر داده و امکانات پشتیبان‌گیری/بازیابی از بخش «تنظیمات» در دسترس است. قبل از جابه‌جایی رایانه یا نصب نسخهٔ جدید، یک نسخهٔ پشتیبان تهیه کنید.

برای آماده‌سازی برنامه جهت استفادهٔ رسمی، ابتدا از بخش «تنظیمات ← پشتیبانی و داده» یک پشتیبان بگیرید و سپس گزینهٔ «شروع رسمی بدون دادهٔ نمونه» را انتخاب کنید. این عملیات با تأیید شما همهٔ داده‌های فعلی را پاک می‌کند، تنظیمات فروشگاه را نگه می‌دارد، واحدهای پایه و کاربر مدیر را دوباره می‌سازد و پیش از پاک‌سازی یک نسخهٔ پشتیبان خودکار ایجاد می‌کند.

## ساختار پروژه

| مسیر | کاربرد |
| --- | --- |
| `main.js` | فرایند اصلی Electron و پنجرهٔ برنامه |
| `preload.js` | API امن بین رابط کاربری و فرایند اصلی |
| `renderer.js` / `styles.css` | رابط کاربری فارسی |
| `src/main/database.js` | لایهٔ SQLite و عملیات داده |
| `src/main/domain/` | منطق دامنه، ازجمله فروش و مرجوعی |
| `test/` | آزمون‌های خودکار |
| `docs/` | دفترچهٔ راهنما و تصاویر آموزشی |
| `build-portable.ps1` | ساخت بستهٔ قابل‌حمل ویندوز |
